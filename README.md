# THE BACK DOOR

### A Project by David Grand

**Artificial Intelligence | Algorithmic Management | Human Governance | Interactive Storytelling**

*The Back Door* is an evolving creative and research initiative exploring artificial intelligence, autonomous systems, institutional decision making, and human authority.

The project connects a forthcoming techno thriller novel, an interactive multiplayer strategy game, and research into the consequences of increasingly autonomous technologies.
